# Simple Kanban Web Application

This web application is a small personal project, written in HTML, CSS and JavaScript.

From a personal development standpoint, it is a first introduction to JavaScript, and a second attempt at building a web application. <br>(_My first non-solo attempt, which was a collaborative Makers Academy project in Python, can be found [here](https://github.com/tsukuyomji/Makersbnb-team-project))_.

The web application is intended to be a functioning Kanban board, with the following main features:
- [x] Static Kanban Lists
- [x] Create a Task
- [ ] Edit a Task 
<br>(_currently, you can delete a task, and create a new task_)
- [x] Delete a Task
- [x] Drag and Drop a Task
- [x] Grey out and strikethrough "Done" Tasks

Nice to haves:
- [ ] Dark Mode

Future ideas:
- [ ] Adding a backend with user accounts.
<br>(_GitHub pages cannot host the backend, so currently some backend is written but not in use_)
